# BuySooner Consumer

Consumer-facing OnHome / BuySooner website prototype.

## Purpose

This repository is the working prototype for the BuySooner customer journey. The site is being designed page-by-page around a simple conversion flow:

1. Understand the benefit
2. See the buying-power impact
3. Understand how BuySooner works
4. Understand the economics
5. Check likely eligibility
6. Take the next step

The prototype is intentionally separate from the BuySooner investor presentation.

## Current build

- Page 1: Home / landing page
- Responsive desktop and mobile styling
- CTA hierarchy centred on “See my buying power” and “Check my eligibility”

Further pages will be added after each page is reviewed and agreed.
